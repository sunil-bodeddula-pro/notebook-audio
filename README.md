# notebook-audio

Audio episodes for [interviewkata.com](https://interviewkata.com): one two-person conversation per page (Sam asks, Priya explains).

- Files mirror the site's paths: `patterns/21-array-string-basics.ogg` belongs to `site/patterns/21-array-string-basics.html`.
- Each `.ogg` (Opus, mono, 24 kHz) has a `.json` beside it with the start and end time of every line.
- Generated by `build/audio_build.py` in the toolkit from the scripts in `build/audio-src/`, using the open-source Kokoro voice model. Don't edit these files by hand; change the script and re-render.
- Published with GitHub Pages; the site's players load from `https://sunil-bodeddula-pro.github.io/notebook-audio/`.
